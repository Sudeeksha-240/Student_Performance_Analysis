# Student Performance Analytics

A full-stack academic analytics designed to analyze, track, and improve student performance using data-driven insights.

## Key Features
- Semester-wise performance analysis
- Subject-wise marks visualization
- CGPA calculation based on credits
- Strength & weakness identification
- At-risk subject detection
- Performance trend tracking

## Tech Stack
- Frontend: React, Chart.js, CSS
- Backend: Node.js
- Database: MySQL 

## Purpose
Built as a personal project to understand how data analytics can improve academic performance and decision-making.

## Future Enhancements
- Backend integration
- Machine learning-based CGPA prediction
- Student login & profiles
- Recommendation system
